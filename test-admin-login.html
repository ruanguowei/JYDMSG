🔧 管理员登录问题排查

问题诊断清单
  • 检查云函数是否已部署
  • 检查数据库中是否有 admin 集合
  • 检查 admin 集合中是否有账号数据
  • 检查账号密码是否正确
  • 检查页面路由是否正确注册
第一步：部署云函数
  1. 打开微信开发者工具
  2. 找到左侧文件树中的 cloudfunctions 文件夹
  3. 右键点击 quickstartFunctions 文件夹
  4. 选择 "上传并部署：云端安装依赖"
  5. 等待部署完成（可能需要几分钟）
注意：新增的云函数必须重新部署才能生效！
第二步：配置管理员账号
  1. 打开云开发控制台（点击微信开发者工具顶部的"云开发"按钮）
  2. 进入左侧"数据库"菜单
  3. 查找是否有 admin 集合
    • 如果没有：点击"+"号创建新集合，命名为 admin
    • 如果有：继续下一步
  4. 点击 admin 集合，然后点击"添加记录"
  5. 在 JSON 编辑器中输入以下内容：
    {
    "account": "admin",
    "password": "123456"
    }
  6. 点击"确定"保存
请根据需要修改账号和密码。部署到生产环境时请使用强密码！
第三步：测试登录
  1. 在微信开发者工具中重新编译小程序（点击"编译"按钮或按 Ctrl+B）
  2. 打开小程序，进入专家评选 → 获取结果页面
  3. 点击底部的"管理员登录"按钮（橙色按钮）
  4. 输入账号：admin
  5. 输入密码：123456（或你设置的密码）
  6. 如果验证成功，会显示"验证成功"并自动跳转到管理员面板
第四步：查看调试日志
如果登录失败，请查看控制台输出：
  1. 打开微信开发者工具的"控制台"选项卡
  2. 查看是否有错误信息
  3. 特别关注以下几种错误：
    • 账号或密码错误 - 检查数据库中的账号密码
    • 网络异常 - 检查云函数是否部署成功
    • 未知的云函数类型 - 检查云函数是否正确注册
    • navigateTo fail - 检查 app.json 中是否注册了 admin-panel 页面
常见问题解决
问题1：点击"管理员登录"没有反应
解决：检查 pages/expert-results/index.js 是否正确添加了 openAdminLogin 方法
问题2：提示"账号或密码错误"
解决：
  1. 检查数据库 admin 集合中是否有数据
  2. 确认输入的账号密码与数据库中完全一致（区分大小写）
问题3：验证成功但没有跳转
解决：检查 app.json 的 pages 数组中是否包含 "pages/admin-panel/index"
问题4：提示"网络异常"
解决：
  1. 检查云函数是否部署成功
  2. 在云开发控制台查看云函数日志
  3. 确认云开发环境已初始化
验证清单
✓ 云函数状态： 需要手动检查
在云开发控制台 → 云函数中查看 quickstartFunctions 的部署时间
✓ 数据库配置： 需要手动检查
在云开发控制台 → 数据库中查看 admin 集合
✓ 页面注册： 已自动配置
admin-panel 页面已在 app.json 中注册
✓ 云函数路由： 已自动配置
verifyAdmin 已在 index.js 中注册

如果按照以上步骤操作后仍有问题，请查看控制台的具体错误信息

💡 提示：最常见的原因是忘记部署云函数
