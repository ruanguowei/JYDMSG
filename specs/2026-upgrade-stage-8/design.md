# 2026 升级第 8 阶段：设计与影响范围

## 新增文件

- `tests/helpers/stage8FlowSimulator.js`

## 模拟链路

```text
生成合成报名数据
→ 按 workCode 清洗重复记录
→ 初评 A/B/C/D 评分
→ 生成初评结果
→ 终评 A/B/C/D 评分
→ 生成最终 320 件结果
→ 生成入围/获奖证书记录
→ 注入证书替换版本
→ 输出统计闭合报告
```

## 关键设计

- 清洗以 `workCode` 为主键，避免同一人多件作品被误判为重复。
- 合成数据保留同一姓名/手机号多作品场景。
- 评分使用第 5 阶段的 `calculateRubric()`。
- 证书使用第 7 阶段的 `buildCertificateRecord()`。
- 最终结果确保覆盖至少一件视频作品，保证视频链路被测试到。

## 输出报告

报告包含：

- 输入条数
- 清洗后条数
- 去重数量
- 初评结果数量
- 终评评分数量
- 最终结果数量
- 证书数量
- 作品编号重复数
- 排名连续性
- 视频作品数量
- 最终视频作品数量
- 五类作品分布
