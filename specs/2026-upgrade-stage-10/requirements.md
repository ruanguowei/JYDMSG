# 2026 升级第 10 阶段：测试环境验收与生产上线准备需求

## 目标

在不触碰生产业务数据的情况下，证明升级具备上线条件。

## 本阶段本地完成范围

- 新增本地升级就绪检查脚本：
  - `scripts/upgrade-readiness-check.js`
- 新增 npm 命令：
  - `npm run check:upgrade-readiness`
- 检查内容：
  - 关键文件存在。
  - 测试/生产环境 ID 存在。
  - 聚合云函数关键路由存在。
  - 危险操作仍只开放预检。
  - 分层测试命令存在。

## 必须等云环境可用后完成

- 测试环境创建 2026 集合和索引。
- 测试环境导入合成数据。
- 测试环境完成真实云函数链路。
- 微信开发者工具编译。
- 真机验证。
- 生产环境资源创建。
- 生产功能开关默认关闭。
- 小程序体验版和审核。
