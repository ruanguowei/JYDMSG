## 腾讯云后台填数约定

先录艺术家，再录其馆藏。建议馆藏 `artistId` 直接填写艺术家文档 `_id`；兼容已有独立业务 `artistId`，若使用业务编号应保证唯一。姓名可重名，不能用姓名关联。

| 集合 | 字段 | 类型与用途 |
| --- | --- | --- |
| museum_artists | name | 字符串，姓名 |
| museum_artists | avatar | 字符串，照片的 cloud:// 文件 ID 或长期有效 HTTPS 地址 |
| museum_artists | intro | 字符串，简介，支持换行 |
| museum_artists | representativeWorks | 可选数组；填馆藏文档 _id 字符串，或 `{collectionId: "馆藏文档ID"}`；独立作品可填 `{title: "作品名称", image: "cloud://文件ID"}` |
| museum_collections | title | 字符串，作品名称 |
| museum_collections | artistId | 字符串，对应艺术家文档 _id 或其业务 artistId |
| museum_collections | artistName | 字符串，作者姓名，供列表显示和搜索；详情优先采用关联档案姓名 |
| museum_collections | period | 可选字符串，如“当代” |
| museum_collections | coverImage | 字符串，封面 cloud:// 文件 ID 或长期有效 HTTPS 地址 |
| museum_collections | detailImages | 可选字符串数组，更多作品图片，最多展示 20 张 |
| museum_collections | intro | 字符串，作品介绍，支持换行；兼容旧 description |
| 两表 | status | 字符串，填 `published` 才展示；草稿可填 `draft` |
| 两表 | sortOrder | 数字，建议始终填写，越小越靠前；相同时按文档 _id 稳定排序 |

代表作品未填写或配置引用全部失效时，展示该艺术家的前 3 件已发布馆藏。指定代表作品仅接受同一艺术家的已发布馆藏，保持配置顺序并去重；独立作品图片可预览，不跳转不存在的馆藏。没有已发布关联艺术家时仍显示作者姓名，但不提供跳转。馆藏和艺术家照片均等比完整显示，不拉伸；馆藏无封面时使用第一张有效详情图片，无图显示占位。

关联规则以文档编号优先。业务编号重复或碰撞他人文档编号时，只有解析后仍归属于当前档案的业务别名才参与关联查询；前端“关联馆藏”优先传档案 `_id`。录入时优先采用文档编号，可以避免这类歧义。

不要将临时签名下载链接作为长期图片地址。正式上线前以真实图片检查加载、预览与存储访问权限。
