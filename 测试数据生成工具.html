🎨 自定义生成
根据需要自定义作品数量
wx.cloud.callFunction({ name: 'quickstartFunctions', data: { type: 'generateTestData', totalCount: 600, // 自定义总数 includeHkMacauTaiwan: true, // 是否包含港澳台（20件） includeVision: true // 是否包含视界类（30件） } });
📊 参数说明：
• totalCount: 总作品数量
• includeHkMacauTaiwan: 是否生成20件港澳台作品
• includeVision: 是否生成30件视界类作品

实际参赛数量计算：
参赛数 = totalCount - 港澳台数 - 视界类数
例如：totalCount=700, 则参赛数=700-20-30=650件

⚠️ 重要提示

  • 所有生成的数据都会标记 _isTestData: true
  • 清理时只会删除测试数据，不影响真实数据
  • 建议在测试环境中使用，不要在生产环境生成大量测试数据
  • 每次生成可能需要几秒到几十秒，请耐心等待
